# 증강 라인 — 던전 크롤러 프로토타입

근접·원거리 저격·광역 공격 중 하나의 프레임을 선택해 방을 돌파하는 2D 탑다운 액션 로그라이트입니다. 클래스마다 전용 핵심 증강 10종이 있으며, 중앙 BUS에서 신호를 배선해 증강을 가동하고 정해진 순서로 통과시키면 수치 상승이 아닌 새로운 전투 규칙이 해금됩니다.

회전 라우터·직각 분배기·과급 증폭기·지연 리피터·집속 렌즈·극성 반전기는 무제한 설계할 수 있지만 1–2 FRAME RAM과 공간을 사용합니다. 같은 핵심 증강도 도구에 따라 RAW·OVERDRIVE·ECHO·PRECISION·UTILITY로 가공되며 피해, 공격 주기, 범위, 후속 공격, 방어 성향이 달라집니다. 분배기는 두 갈래를 72% 처리량으로 만들어 직렬 고출력과 병렬 다기능 사이의 손익을 만듭니다.

가장 긴 유효 신호 체인은 9개 주력 플레이스타일 중 하나를 TIER I–III로 가동합니다. 핵심 증강은 2–4 RAM, 공정 도구는 1–2 RAM, 활성 프로토콜은 1 RAM을 사용하며 최대 용량은 레벨에 따라 10–24 RAM으로 증가합니다. 쓰지 않는 핵심 증강은 0 RAM 보관함에 넣고 언제든 다시 장착할 수 있습니다.

## 실행

`index.html`을 브라우저로 열거나 다음 명령으로 로컬 서버를 실행합니다.

```powershell
node server.cjs
```

그다음 `http://127.0.0.1:4173`에 접속합니다.

## 조작

- WASD / 방향키: 이동
- 마우스: 공격 방향 지정(플레이어 본체는 이동 방향을 바라봄)
- 좌클릭 / J: 클래스 기본 공격
  - 근접: 클릭마다 1회 횡베기(왼쪽→오른쪽, 오른쪽→왼쪽 교대)
  - 저격: 조준 방향으로 레일탄 1발
  - 광역: 조준 지점으로 폭발 유탄 1발
- Space: 대시
- E: 열린 북쪽 문 진입
- Tab: 공장 보드
- 획득한 공정 도구 카드: 실제 신호가 이어지는 밝은 결합 셀에 배치
- R / 우클릭 / 셀 화살표: 회전 라우터·직각 분배기 방향 전환
- 숫자키 1–3 / Enter: 증강 임시 선택 / 선택 확정
- Esc / P: 일시정지, 공장 배치 완료 시 Esc로 전투 복귀
- R: 라인 정지 화면에서 즉시 재시작

전투 HUD의 조준점·쿨다운 링·주력 플레이스타일 배지와 공장 보드의 RAM 계기·리액터 강조선으로 현재 빌드 상태를 확인할 수 있습니다.

HUD, 선택 화면, 공장, 일시정지 화면은 하나의 가상 UI 스테이지에서 동일 비율로 확대·축소됩니다. 세로형·정방형·와이드 화면별 기준 해상도를 자동 선택하며, 창 크기를 바꾸면 새로고침 없이 즉시 다시 맞춥니다. 전투 캔버스는 실제 화면 해상도를 그대로 사용하므로 UI 배율과 관계없이 플레이 영역을 모두 채웁니다.

상세 설계는 [GAME_DESIGN.md](GAME_DESIGN.md)를 참고하세요.

## 증강 검증

통합 검증은 `node verify-game.cjs`로 실행합니다. 30개 증강·30개 프로토콜·6개 공정 도구, 중앙 BUS 단일 입력, 실제 결합 셀 전용 배치, 신호 분기와 72% 처리량, 도구 사이 프로토콜, 30개 증강 단독 활성과 전투 효과, 9개 주력 플레이스타일, RAM 초과 거부·보관 흐름과 렌더링을 검사합니다. 브라우저에서는 `http://127.0.0.1:4173/?test=1`로 접속한 뒤 **전체 빌드 진단**을 눌러 동일한 런타임 진단을 실행할 수 있습니다.

로컬 서버를 켠 상태에서 `node verify-responsive.cjs`를 실행하면 Chrome 또는 Edge로 `1920×1080`, `1024×1024`, `390×844`, `844×390` 화면을 렌더링합니다. 시작 화면·전투 HUD·공장 셸의 잘림, 가로 오버플로, 비율 프로필, 실시간 창 크기 변경을 함께 검사합니다.
