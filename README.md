# 증강 라인 — 던전 크롤러 프로토타입

근접·원거리 저격·광역 공격 중 하나의 프레임을 선택해 방을 돌파하는 2D 탑다운 액션 로그라이트입니다. 클래스마다 전용 행동 증강 10종이 있으며, 무한 조립 레일의 같은 행에서 특정 부품을 좌→우 순서로 이으면 수치 상승이 아닌 새로운 전투 규칙이 해금됩니다.

가장 긴 연속 라인은 9개 주력 플레이스타일 중 하나를 TIER I–III로 가동해 기본 공격·이동·방어 루프를 눈에 띄게 바꿉니다. 장착 모듈은 2–4 FRAME RAM, 활성 링크는 1 RAM을 사용하므로 제한 용량 안에서 범용 행동과 강한 연속 빌드의 득실을 따져야 합니다. 쓰지 않는 모듈은 0 RAM 보관함에 넣고 언제든 다시 장착할 수 있습니다.

## 실행

`index.html`을 브라우저로 열거나 다음 명령으로 로컬 서버를 실행합니다.

```powershell
node server.cjs
```

그다음 `http://127.0.0.1:4173`에 접속합니다.

## 조작

- WASD / 방향키: 이동
- 마우스: 공격 방향 지정(플레이어 본체는 이동 방향을 바라봄)
- 좌클릭 / J: 클래스 기본 공격
  - 근접: 클릭마다 1회 횡베기(왼쪽→오른쪽, 오른쪽→왼쪽 교대)
  - 저격: 조준 방향으로 레일탄 1발
  - 광역: 조준 지점으로 폭발 유탄 1발
- Space: 대시
- E: 열린 북쪽 문 진입
- Tab: 공장 보드
- 숫자키 1–3 / Enter: 증강 임시 선택 / 선택 확정
- Esc / P: 일시정지, 공장 배치 완료 시 Esc로 전투 복귀
- R: 라인 정지 화면에서 즉시 재시작

전투 HUD의 조준점·쿨다운 링·주력 플레이스타일 배지와 공장 보드의 RAM 계기·리액터 강조선으로 현재 빌드 상태를 확인할 수 있습니다.

상세 설계는 [GAME_DESIGN.md](GAME_DESIGN.md)를 참고하세요.

## 증강 검증

통합 검증은 `node verify-game.cjs`로 실행합니다. 30개 증강·30개 프로토콜, 9개 주력 플레이스타일의 시그니처 전투 결과, RAM 비용·초과 배치 거부·보관 흐름과 함께 본체/공격 방향 분리 및 렌더링을 검사합니다. 브라우저에서는 `http://127.0.0.1:4173/?test=1`로 접속한 뒤 **전체 빌드 진단**을 눌러 동일한 런타임 진단을 실행할 수 있습니다.
