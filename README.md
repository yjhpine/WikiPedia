# 증강 라인 — 던전 크롤러 프로토타입

세 클래스 중 하나를 선택하고, 전용 증강을 반복 강화해 완성형 진화를 만드는 2D 탑다운 액션 로그라이트입니다. 전투에서 얻은 공정 도구를 중앙 `BUS IN`에서 배선해 증강에 신호를 공급하고, 한정된 FRAME RAM 안에서 강한 단일 라인·분기·도구 조합·완성형 진화 사이의 손익을 설계합니다.

## 핵심 시스템

- 클래스별 행동 증강 10종, 전체 30종
- 같은 증강 재선택 시 `RANK 1 → 2 → 3`, 이후 `LIMIT BREAK +5%`
- 지정된 파트너 두 개가 모두 RANK 2 이상이고 가동 중이면 순서와 무관하게 완성형 진화
- 클래스별 5종, 전체 15종 완성형 진화
- 서로 다른 공정 도구가 같은 신호 경로에서 연속되면 순서와 무관한 `도구 A × 도구 B` 조합
- 6개 도구와 6개 도구 X 조합
- 완성된 진화 수로 TIER I–III가 성장하는 클래스별 3개, 전체 9개 주력 빌드
- 레벨 1의 10 RAM에서 시작해 레벨마다 최대 용량 +2

## 실행

```powershell
node server.cjs
```

브라우저에서 `http://127.0.0.1:4173`에 접속합니다. 테스트 패널은 `http://127.0.0.1:4173/?test=1`에서 열립니다.

## 조작

- WASD / 방향키: 이동
- 마우스: 공격 방향 지정
- 좌클릭 / J: 기본 공격 1회
- Space: 대시
- E: 열린 북쪽 문 진입
- Tab: 공장 보드
- 드래그 또는 클릭 후 배치: NEW PART·STORAGE·드랍 도구를 밝은 결합 셀로 이동
- R / 우클릭 / 셀 화살표: 배치 방향 전환
- 숫자키 1–3 / Enter: 증강 선택 / 확정
- Esc / P: 일시정지 또는 공장 닫기

근접 클래스는 입력 1회당 칼날을 정확히 한 번 휘두르며 좌→우, 우→좌 방향을 교대합니다. 칼날과 기본 사거리는 초기 규격의 2배입니다.

## 빌드 읽는 법

레벨업 카드에는 현재 상태(`NEW`, `RANK n → n+1`, `LIMIT`), 다음 강화 효과, 진화 파트너와 파트너 랭크가 표시됩니다. 공장 출력 패널에서는 다음을 확인할 수 있습니다.

- 가동 증강과 랭크
- 활성화된 도구 X 조합
- 완성형 진화와 파트너 랭크
- 주력 빌드와 TIER
- 현재/최대 FRAME RAM, 처리량, 공격 배율과 공정 성향

세로 화면에서는 공장의 부품·회로·출력을 탭으로 전환합니다. 전체 UI는 세로·정방형·와이드 레이아웃에 맞춰 새로고침 없이 재배치됩니다.

## 검증

```powershell
node --check game.js
node verify-game.cjs
node verify-responsive.cjs
```

`verify-game.cjs`는 30개 증강의 실제 전투 효과, R1→R2→R3→LIMIT 선택 흐름, 15개 순서 없는 진화, 6개 도구 X 조합, 9개 주력 빌드, RAM·신호·보관 흐름을 검사합니다. `verify-responsive.cjs`는 Chrome/Edge로 1920×1080, 1024×1024, 390×844, 844×390 화면의 입력·공장·레벨업·리사이즈 회귀를 검사합니다.
