# 증강 라인 — 던전 크롤러 프로토타입

세 클래스 중 하나를 선택하고, 전용 증강을 반복 강화해 완성형 진화를 만드는 2D 탑다운 액션 로그라이트입니다. 전투에서 얻은 공정 도구를 중앙 `BUS IN`에서 배선해 증강에 신호를 공급하고, 한정된 FRAME RAM 안에서 강한 단일 라인·분기·도구 조합·완성형 진화 사이의 손익을 설계합니다.

## 핵심 시스템

- 근접은 HP 150·피흡 8%·Shift 방벽, 저격은 HP 50·이동 +20%·회피 +35%, 광역은 이동 -16%·주요 폭발 반경 +25%
- 클래스별 행동 증강 10종, 전체 30종
- 같은 증강 재선택 시 `RANK 1 → 2 → 3`, 이후 `LIMIT BREAK +5%`
- 지정된 파트너 두 개가 모두 RANK 2 이상이고 가동 중이면 순서와 무관하게 완성형 진화
- 클래스별 5종, 전체 15종 완성형 진화
- 서로 다른 공정 도구가 같은 신호 경로에서 연속되면 순서와 무관한 `도구 A × 도구 B` 조합
- 6개 도구와 6개 도구 X 조합
- 완성된 진화 수로 TIER I–III가 성장하는 클래스별 3개, 전체 9개 주력 빌드
- 레벨 1의 10 RAM에서 시작해 레벨마다 최대 용량 +2
- 일반 전투 5방 뒤 전용 보스룸, 섹터마다 용광로 거신·프리즘 감시자·공허 레비아탄 순환
- 일부 증강은 1×2·2×1·2×4·4×2 직사각형으로 배선 공간과 단자 위치를 다르게 요구

## 실행

```powershell
node server.cjs
```

브라우저에서 `http://127.0.0.1:4173`에 접속합니다. 테스트 패널은 `http://127.0.0.1:4173/?test=1`에서 열립니다.

## 조작

- WASD / 방향키: 이동
- 마우스: 공격 방향 지정
- 좌클릭 / J: 기본 공격 1회
- Space: 대시(저격은 약 35% 긴 장거리 회피)
- Shift: 근접 클래스 칼날 방벽(0.7초 동안 첫 피해 차단, 4초 재사용)
- E: 열린 북쪽 문 진입
- Tab: 공장 보드
- 드래그 또는 클릭 후 배치: NEW PART·STORAGE·드랍 도구를 밝은 결합 셀로 이동
- R / 우클릭 / 셀 화살표: 배치 방향 전환
- 숫자키 1–3 / Enter: 증강 선택 / 확정
- Esc / P: 일시정지 또는 공장 닫기

근접 클래스는 입력 1회당 칼날을 정확히 한 번 휘두르며 좌→우, 우→좌 방향을 교대합니다. 칼날과 기본 사거리는 초기 규격의 2배이며, 실제 근접 피해의 8%를 회복합니다. 저격은 빠른 이동과 긴 회피를 낮은 체력과 교환하고, 광역은 느린 이동 대신 기본 유탄·초신성·대시 폭탄·궤도 폭격 등 주요 폭발 반경이 25% 넓습니다.

## 보스 진행

각 섹터는 일반 전투 5방과 보스룸 1방으로 구성됩니다. 용광로 거신은 단조 충격·산탄·돌진·지뢰·소환, 프리즘 감시자는 광선·만화경 탄막·거울문·점멸·감옥, 공허 레비아탄은 나선·중력장·잠행·휩쓸기·증식 패턴을 사용합니다. 큰 공격은 원·선·발사 지점 텔레그래프로 먼저 표시됩니다. `?test=1`에서는 `보스룸 이동` 버튼으로 세 보스를 바로 순환 테스트할 수 있습니다.

## 빌드 읽는 법

레벨업 카드에는 현재 상태(`NEW`, `RANK n → n+1`, `LIMIT`), 다음 강화 효과, 진화 파트너뿐 아니라 희귀도·실제 점유 크기·입출력 단자 도면이 표시됩니다. 갈고리·유도 보정기·연쇄 기폭기는 1×2/2×1, 처형 톱니·기동 장전·재귀 폭발식은 2×4/4×2 직사각형입니다. 신규 카드의 도면은 선택 후 NEW PART에 그대로 이어지고, RANK 강화 카드는 기존 모듈의 고정된 물리 레이아웃을 보여줍니다. 공장 출력 패널에서는 다음을 확인할 수 있습니다.

- 가동 증강과 랭크
- 활성화된 도구 X 조합
- 완성형 진화와 파트너 랭크
- 주력 빌드와 TIER
- 현재/최대 FRAME RAM, 처리량, 공격 배율과 공정 성향

전투 HUD는 내구도·경험치·목표·RAM·대시와 현재 클래스의 고유 기술만 표시합니다. 공격 재사용 대기는 조준점에서 확인하고, 상세 증강 수치는 공장 출력에서 확인합니다. 세로 화면에서는 공장의 부품·회로·출력을 탭으로 전환하며 전체 UI는 새로고침 없이 재배치됩니다.

## 검증

```powershell
node --check game.js
node verify-game.cjs
node verify-responsive.cjs
```

`verify-game.cjs`는 5+1 방 주기, 3종 보스의 각 5패턴, 클래스별 전투 정체성, 직사각형 점유와 30개 증강·15개 진화·6개 도구 X 조합·9개 주력 빌드를 검사합니다. `verify-responsive.cjs`는 Chrome/Edge로 네 화면 비율과 세 보스의 실제 패턴 신호·보스 HUD·직사각형 도면을 검사합니다.
