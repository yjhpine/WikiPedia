# 증강 라인 — 던전 크롤러 프로토타입

근접·원거리 저격·광역 공격 중 하나의 프레임을 선택해 방을 돌파하는 2D 탑다운 액션 로그라이트입니다. 클래스마다 전용 행동 증강 10종이 있으며, 무한 조립 레일의 같은 행에서 특정 부품을 좌→우 순서로 이으면 수치 상승이 아닌 새로운 전투 규칙이 해금됩니다. 세 부품 이상을 연속 배치하면 여러 프로토콜이 동시에 연결됩니다.

## 실행

`index.html`을 브라우저로 열거나 다음 명령으로 로컬 서버를 실행합니다.

```powershell
node server.cjs
```

그다음 `http://127.0.0.1:4173`에 접속합니다.

## 조작

- WASD / 방향키: 이동
- 마우스: 공격 방향 지정(플레이어 본체는 이동 방향을 바라봄)
- 좌클릭 / J: 클래스 기본 공격
  - 근접: 클릭마다 1회 횡베기(왼쪽→오른쪽, 오른쪽→왼쪽 교대)
  - 저격: 조준 방향으로 레일탄 1발
  - 광역: 조준 지점으로 폭발 유탄 1발
- Space: 대시
- E: 열린 북쪽 문 진입
- Tab: 공장 보드
- 숫자키 1–3 / Enter: 증강 임시 선택 / 선택 확정
- Esc / P: 일시정지, 공장 배치 완료 시 Esc로 전투 복귀
- R: 라인 정지 화면에서 즉시 재시작

전투 HUD의 조준점·쿨다운 링·행동 상태 카드와 공장 보드의 점멸 셀·적용 변화량을 통해 현재 상태를 확인할 수 있습니다.

상세 설계는 [GAME_DESIGN.md](GAME_DESIGN.md)를 참고하세요.

## 증강 검증

통합 검증은 `node verify-game.cjs`로 실행합니다. 30개 증강·30개 프로토콜 구조와 함께 최소 HUD, 본체/공격 방향 분리, 세 클래스 보간 렌더링을 런타임 스모크 테스트합니다. 브라우저에서는 `http://127.0.0.1:4173/?test=1`로 접속한 뒤 **30 증강 진단**을 눌러 실제 전투 발동과 정방향·역방향 판정도 확인할 수 있습니다.
